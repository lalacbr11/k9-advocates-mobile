## Review and limitations

Launch with `npm run ios`, then use Add Booking on Dashboard or Calendar.
For grouped original fixtures, select October 9, 2026 in Calendar. Add two demo
bookings for one dog to inspect multiple rows. Bookings disappear on app reload.
Filters count each matching dog once and retain its other booking rows. Per-service
unique-dog counters can include the same dog in more than one service; the total
unique-dog count is calculated separately. Domain validation and conflict rules,
fictional fixtures, session saving and the storage proposal were not changed.
No new dependencies, committed screenshots, commit or push in this revision.
Visual approval remains with the project owners.
