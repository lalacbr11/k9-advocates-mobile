## Automated Test Suite

The suite is saved in `tests/dogs.test.cjs` and runs with `npm test`. Setup and run instructions are in [tests/README.md](../../tests/README.md). It uses Node's built-in test runner and the project's existing TypeScript compiler, with no extra dependencies and no simulator.

**Scope:** shared dog records and pure logic (`src/data/dogRecords.ts`, `src/data/dashboard.ts`, `src/logic/dogs.ts`). It does not test screens, navigation, keyboard behavior, photo loading, or accessibility; those rely on the manual results above.
